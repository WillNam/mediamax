# 平台数据边界

| 平台 | 通常可公开观察 | 通常需用户后台 | 不要假装能拿到 |
|---|---|---|---|
| 抖音 | 作品、点赞、评论、部分播放展示 | 完播、平均观看、涨粉、主页访问、粉丝画像 | 他人精确 GPM、投流花费、私域成交 |
| 视频号 | 作品与互动公开字段因版本而异 | 完整播放与关注效率 | 稳定的全量公开播放榜 |
| 小红书 | 笔记、点赞、收藏、评论 | 曝光、涨粉、搜索来源 | 他人商业笔记后台 |
| YouTube | 播放、赞、评论、订阅（频道级） | 点击率、观众来源、收入 | 精确 AdSense 实收（第三方仅为估） |
| B 站 | 播放、弹幕、硬币、收藏 | 后台来源与转化 | 他人充电实收 |

## 采集红线

- 不用经营主账号登录态做自动化竞品采集。
- 不绕过验证码、付费墙、试用风控。
- 遇限流即停。
- 引用评论去标识化。

## 起号阶段优先看（自有号）

1. 前 3 秒 / 关键节点留存  
2. 平均观看时长与完播  
3. 每千播新关  
4. 评论是否命中定位词  
5. 制作时长（产能可否持续）
