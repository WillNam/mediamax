# MediaMax Skill 产品矩阵

面向自媒体博主、内容团队、品牌媒介的可组合 Agent Skill 套件。  
原则：**一个 Skill 只做一类工作**；总控路由交给起号教练 / 内容工作流。

## 0. 已有能力（不重复建设）

| Skill | 岗位 | 工作 |
|---|---|---|
| `ai-launch-coach` / `self-media-launch-coach` | 新人 / 主理人 | 起号诊断、四榜、30 天实验 |
| `self-media-content-workflow` | 主编 | 全流程路由与确认点 |
| `self-media-content-brief` | 策划 | 单篇创作简报 |
| `self-media-content-strategy` | 策略 | 定位、栏目、日历 |
| `self-media-trend-radar` | 研究 | 热点与竞品拆解 |
| `self-media-short-video` | 编导 | 口播 / 分镜 / 字幕 |
| `self-media-platform-copywriting` | 文案 | 多平台原生改写 |
| `self-media-content-analytics` | 数据 | 单篇 / 周 / 月复盘 |
| `self-media-traffic-planner` | 运营 | 发布排期 |
| `self-media-content-delivery` | 交付 | 版本与发布包 |
| `self-media-wechat-publisher` | 公众号 | 排版与草稿 |

## 1. 按岗位补齐的新 Skill

### A. 个人博主 / 创作者

| Skill | 解决什么 | 标准交付 |
|---|---|---|
| `self-media-profile-optimizer` | 主页像门店橱窗，转化差 | 简介三版、置顶策略、头图文案 |
| `self-media-cover-director` | 封面不点开 | 封面标题 5 版 + 构图说明 |
| `self-media-search-seo` | 只会追热点，没有搜索流量 | 搜索词池 + 可拍搜索选题 |
| `self-media-series-factory` | 单条能写，系列撑不住 | 系列大纲 + 批量钩子包 |
| `self-media-clip-factory` | 长内容浪费 | 切片清单 + 二次包装标题 |

### B. 内容运营 / 社区

| Skill | 解决什么 | 标准交付 |
|---|---|---|
| `self-media-comment-ops` | 评论区浪费互动 | 回复策略、置顶评论、种子话术 |
| `self-media-matrix-ops` | 多号互相抢戏或同质 | 矩阵分工表 + 错峰排期 |
| `self-media-private-domain` | 公域涨粉不沉淀 | 关注→私信→社群路径图 |

### C. 直播 / 带货

| Skill | 解决什么 | 标准交付 |
|---|---|---|
| `self-media-live-script` | 直播东聊西聊无转化 | 分时段脚本 + 逼单节奏 + 话术卡 |

### D. 商务变现

| Skill | 解决什么 | 标准交付 |
|---|---|---|
| `self-media-brand-deal` | 商单谈不清、交付乱 | 商单 Brief、报价区间、验收清单 |
| `self-media-media-kit` | 品牌方看不懂你值多少 | 一页媒介资料 + 刊例建议 |

### E. 品牌媒介 / 公关

| Skill | 解决什么 | 标准交付 |
|---|---|---|
| `brand-media-brief` | 找达人靠感觉 | 投放 Brief + 达人匹配维度 |
| `self-media-crisis-desk` | 翻车没预案 | 分级响应 + 口径包 |

## 2. 角色组合包（售卖 / 安装建议）

| 组合包 | 包含 Skill | 适合谁 |
|---|---|---|
| **起号包** | launch-coach + profile + cover + search-seo | 0–1 万粉新人 |
| **日更包** | brief + short-video + cover + comment-ops + analytics | 个人日更博主 |
| **团队包** | workflow + strategy + series-factory + matrix-ops + delivery | 小团队 / MCN 小组 |
| **变现包** | brand-deal + media-kit + private-domain + live-script | 开始接商单 / 直播 |
| **品牌媒介包** | brand-media-brief + compliance + crisis-desk + analytics | 品牌投放与公关 |

## 3. 设计原则

1. **输入少、交付固定**：缺信息最多问 3 个问题。
2. **不越权**：不登录他人账号、不自动群发、不绕过平台规则。
3. **证据分级**：已确认 / 样本模式 / 弱信号 / 无法判断。
4. **可组合**：每个 Skill 写清「上游输入 / 下游交棒」。
5. **平台原生**：抖音、视频号、小红书、公众号字段分开写。

## 4. 实现优先级

| 优先级 | Skill | 原因 |
|---|---|---|
| P0 | profile-optimizer, cover-director, comment-ops, search-seo | 起号后立刻高频用 |
| P0+ | viral-breakdown, account-doctor, benchmark-finder, headline-lab | 平台最热能力的优化版 |
| P1 | series-factory, clip-factory, brand-deal, media-kit, voice-dna, repurpose, publish-checklist | 稳定更新与变现 |
| P2 | live-script, private-domain, matrix-ops | 团队 / 直播阶段 |
| P3 | brand-media-brief, compliance, crisis-desk | 品牌与风险管理 |
