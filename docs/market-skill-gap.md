# 平台热门 Skill 能力对照与 MediaMax 优化选型

更新日期：2026-08-13

## 1. 市场上最热的能力簇

| 热门能力 | 代表产品 / Skill | 用户为什么买账 | MediaMax 原状 |
|---|---|---|---|
| 单条爆款深拆 | social-account-doctor / lingzao note-breakdown / viral-content-breakdown | 给链接就能拆钩子/封面/结构 | 仅有模板，无独立 Skill |
| 账号体检（老号） | account-doctor / xhs-account-diagnosis | 「为什么没人看」比起号更刚需 | launch-coach 偏冷启动 |
| 真对标筛选 | xhs-benchmark-account-finder | 过滤大号/断更/偶然爆 | 有四榜，缺筛选闸门 Skill |
| 标题 / 封面点击实验室 | headline-optimizer / cover-lab | A/B 与公式化 | 有 cover，缺标题专项 |
| 人设 Voice DNA | creator-studio /voice-setup | 解决 AI 味 | 缺失 |
| 一鱼多吃 | creator-studio /repurpose | 一条母题多平台 | 有 copywriting，缺流程 Skill |
| 发布前检查 | lingzao preflight / compliance | 减少扑街与违规 | compliance 有，缺运营向清单 |
| 自动发布 / 爬虫采集 | douyin-publisher / tikhub 链路 | 省事 | **刻意不做**（合规边界） |
| 成片渲染 Remotion | claude-shorts / video_skills | 一键成片 | 可选后续，本轮不做重依赖 |

## 2. 本轮优化原则

1. **学机制，不抄闭源实现**；不接需登录态的爬虫发布能力。  
2. **比热门版更好**：强制证据分级、可迁移/不可抄分离、最多问 3 问、固定交付包。  
3. **中文平台原生**：抖音 / 视频号 / 小红书字段与互动信号（赞藏转评）。  

## 3. 本轮新增（优化版）

| 新 Skill | 对标热门点 | MediaMax 增强 |
|---|---|---|
| `self-media-viral-breakdown` | 爆款拆解 | 互动结构比（转藏驱动 vs 完播驱动）+ 机制仿写非逐字抄 |
| `self-media-account-doctor` | 账号体检 | 阶段诊断 + 一票否决项 + 5/24/7 天抢救动作 |
| `self-media-benchmark-finder` | 真对标 | 粉丝区间闸门 + 主对标/相邻/单样本/不推荐四标签 |
| `self-media-headline-lab` | 标题优化 | 8→3 漏斗 + 点击假设 + 与封面联测 |
| `self-media-voice-dna` | voice-setup | 中文禁用套话库 + 人设资产文件 |
| `self-media-repurpose` | repurpose | 母题共享、表达重写；禁止一稿多发 |
| `self-media-publish-checklist` | 发布前检查 | 运营项 + 合规项合并成可勾选清单 |

## 4. 明确不做（本轮）

- 自动登录发布、批量私信、绕过风控采集  
- 依赖付费第三方数据 API 才能运行的主路径（可作可选增强，不作为默认）  
- Remotion / 数字人成片重依赖（另立专题）
