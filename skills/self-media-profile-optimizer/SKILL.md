# 主页转化优化

## 目标

把主页变成「3 秒看懂你是谁、为什么关注、下一步点哪里」。

## 输入

- 平台、赛道、目标受众
- 当前简介与置顶（截图或原文）
- 本阶段目标：涨粉 / 信任 / 私信 / 商品

缺信息最多问 3 个问题。

## 流程

1. 诊断：身份是否清晰、利益是否具体、信任证据是否可见、CTA 是否单一。
2. 写 3 版简介：结果向 / 身份向 / 冲突向。
3. 置顶策略：1 条定位片 + 1 条代表作 + 1 条转化/系列入口（按平台调整）。
4. 行动入口：关注理由、私信关键词、商品或社群只留一个主路径。

## 交付

1. 诊断结论（3 条内）
2. 简介三版 + 推荐版
3. 置顶内容任务书
4. 主页视觉文案（头图大字 / 背景说明）
5. 7 天观察指标：主页访问→关注率
