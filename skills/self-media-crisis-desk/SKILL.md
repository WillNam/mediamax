# 舆情应对台

## 分级

| 级别 | 特征 | 动作 |
|---|---|---|
| L1 | 个别质疑 | 解释或置评，不扩写 |
| L2 | 评论区失控 | 统一口径、停发争议话题 |
| L3 | 外溢到社群/媒体 | 事实时间线、必要时暂停商单 |
| L4 | 法律/安全风险 | 停更争议内容，转人工法务 |

## 交付

1. 事件时间线（已知事实 vs 传言）
2. 级别判断与 24 小时行动清单
3. 对外口径（短/中）与对内通知
4. 不说清单
5. 复盘项：流程漏洞、内容边界

## 红线

不建议删帖掩盖违法事实；不攻击举报者；不伪造证据。
