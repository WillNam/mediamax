# 搜索选题与 SEO

## 目标

在热点之外，建立可持续的搜索流量选题池。

## 方法

1. 明确受众会搜的问题句式（怎么、多少、对比、避坑、清单）。
2. 从用户提供的词、评论、同行标题中提取词根。
3. 分三级：主词 / 长尾 / 场景词。
4. 每条选题绑定一个搜索意图：认知 / 比较 / 交易 / 操作。

## 交付

1. 词池表（主词、长尾、意图、竞争粗判）
2. 10–20 条可拍搜索选题
3. 标题公式（含主词自然露出）
4. 合集/系列命名建议
5. 本周优先拍的 Top 5

## 注意

- 不编造平台后台搜索指数；无数据时标「待用户用创作者后台核验」。
- 搜索题也要有钩子，不能变成说明书标题。
