# 品牌媒介 Brief

## 输入

- 产品、目标、预算区间、档期
- 目标人群与必达/禁达平台
- 已有达人名单或类目

## 交付

1. 一页投放 Brief（目标、信息、禁区、KPI）
2. 达人匹配维度：受众重合、内容风格、商单痕迹、性价比、风险
3. 初筛表头（供表格使用）
4. 合作形式建议：短视频/直播/系列/矩阵
5. 验收与披露要求

## 注意

- KPI 区分曝光、互动、涨粉、线索、成交；不把播放量直接当成交。
- 合规与广告法交棒 `self-media-compliance`。
