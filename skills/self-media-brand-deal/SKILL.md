# 商单协作

## 原则

- 先边界后创意：不能说什么比金句更重要。
- 报价与权益对表：一条视频 ≠ 永久授权。
- 必须商业披露，遵循平台与广告法。

## 流程

1. 澄清产品、目标、平台、档期、使用权。
2. 评估匹配度：受众重合、口碑风险、制作成本。
3. 输出合作 Brief 与报价结构（创作费/授权/修改轮次）。
4. 写可拍角度 3 个（不硬广、可自证）。
5. 验收清单与修改规则。

## 交付

1. 匹配度结论：接 / 改条件接 / 拒（含理由）
2. 商单 Brief（一页）
3. 报价表（可区间）
4. 脚本方向与禁用词
5. 披露文案 + 验收清单
