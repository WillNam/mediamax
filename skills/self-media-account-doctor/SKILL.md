# 账号体检医生（优化版）

## 何时使用

- 已有账号但卡住  
- 「这条为什么不爆」+ 后台截图  
- 需要判断是定位、包装、选题还是执行问题  

冷启动从 0 开始 → 用 `ai-launch-coach`。

## 输入优先级

1. 主页简介 / 置顶 / 最近 8–12 条表现  
2. 后台截图（完播、平均观看、关注来源）  
3. 已知对标或赛道词  

## 诊断框架

### 1. 阶段

冷启动 / 波动增长 / 稳定 / 衰退 / 定位漂移

### 2. 一票否决（有则先修）

- 主页 3 秒看不懂是谁  
- 封面无钩子或封面顺序错误（小红书首图）  
- 标题承诺正文不兑现  
- 连续同质选题无新证据  
- 明显违规用语

### 3. 差距归因（只选主因）

定位错位 / 包装（标题封面钩子）/ 内容结构 / 更新节奏 / 人群不匹配 / 样本不足

### 4. 行动清单（必须可执行）

| 优先级 | 窗口 | 动作 |
|---|---|---|
| P0 | 5 分钟 | 改封面/标题/置顶之一 |
| P1 | 24 小时 | 补互动钩或置评 |
| P2 | 7 天 | 唯一实验（只改一个变量） |

## 交付

1. 阶段结论 + 主因（一句话）  
2. 一票否决项（有/无）  
3. 证据与缺口  
4. P0/P1/P2 清单（含可粘贴改写）  
5. 下次复盘要看的 3 个指标  

## 交棒

- 主页装修 → `self-media-profile-optimizer`  
- 爆款机制学习 → `self-media-viral-breakdown`  
- 找真对标 → `self-media-benchmark-finder`
