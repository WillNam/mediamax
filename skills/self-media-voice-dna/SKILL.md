# 人设 Voice DNA（优化版）

## 目标

让输出听起来像「这个人」，而不是通用营销腔。

## 访谈（分批，最多 3 轮）

**轮 1**
1. 三个语气词（如：冷静、直接、有点毒舌）  
2. 真实口头禅 / 结尾习惯  
3. 最讨厌的 AI 套话  

**轮 2**
4. 绝对不碰的题材  
5. 喜欢的 2–3 个创作者，各学哪一点  
6. 常提起的个人经历标签  

**轮 3**
7. 表情政策：无 / 少 / 中  
8. POV：我 / 你 / 我们  
9. CTA：硬 / 软 / 常常没有  

## 写入资产

保存为用户目录 `self-media/voice-dna.md`（或项目指定路径），结构用 [assets/voice-dna-template.md](assets/voice-dna-template.md)。

## 硬规则（生成时）

- 先读 voice-dna；若仍是占位符，先补访谈。  
- 默认禁用（可追加）：赋能、抓手、闭环、打通、底层逻辑、干货满满、家人们、宝子们（除非用户口语真实在用）。  
- 每条内容映射到用户栏目，而不是随机热点腔。

任何文案 / 脚本 Skill 在动笔前读取本资产。
