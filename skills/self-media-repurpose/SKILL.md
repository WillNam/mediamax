# 一鱼多吃（优化版）

## 输入

- 母题 / 口播稿 / 链接 / 文稿  
- 目标平台列表  
- voice-dna（若有）

## 规则

| 共享 | 必须重写 |
|---|---|
| 事实、证据、边界、核心判断 | 标题、钩子、例子顺序、信息密度、视觉、CTA、标签 |

若多平台只有长短差异 → 判定失败，重写。

## 默认改装矩阵

1. **短视频版**：钩子 + 一个判断 + 一个行动（≤60s）  
2. **小红书图文**：封面大字 + 分页信息任务 + 收藏点  
3. **公众号/长文**：结构论证 + 案例 + 边界  
4. **朋友圈/社群短帖**：1 个场景句 + 1 个问题  

按用户需要裁剪，不必四件套全做。

## 交付

- 各平台完整可发草稿（或发布字段）  
- 哪些证据仍缺  
- 建议发布顺序（先强势平台）

## 交棒

细脚本 → `self-media-short-video`  
归档 → `self-media-content-delivery`
