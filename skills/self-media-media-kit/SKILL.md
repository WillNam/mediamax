# 媒介资料包（Media Kit）

## 输入

- 定位、平台数据（用户提供，不编造）
- 代表作链接
- 可合作形式：短视频/直播/图文/矩阵

## 结构

1. 一句话定位
2. 受众谁（可验证描述，不吹）
3. 核心数据（标注日期与来源）
4. 代表案例 3 个（结果写清是否可公开）
5. 合作形式与交付周期
6. 刊例：按形式给区间，注明含几轮修改、授权范围

## 交付

1. 一页 Media Kit（Markdown）
2. 短版私信建联话术
3. 数据缺口清单（需用户补截图）
4. 不建议承诺的条款（保量、永久授权等）

## 注意

公开播放 ≠ 成交；无后台数据时用「样本观察」表述。
