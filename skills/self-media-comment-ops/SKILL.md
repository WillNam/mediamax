# 评论区运营

## 目标

把评论区变成第二内容场：澄清、深化、导流、筛线索。

## 红线

- 不自动用主账号批量回复、点赞、私信。
- 不诱导虚假互动。
- 争议评论先分级，再决定是否公开回应。

## 流程

1. 读取样本评论（用户粘贴或截图）。
2. 分类：认同 / 提问 / 反对 / 求链接 / 引战 / 广告。
3. 设定本条内容的评论目标：澄清 / 加深信任 / 导私域 / 收集选题。
4. 写置顶评论 + 高频回复模板 + 不回复清单。

## 交付

1. 评论分类统计（可粗略）
2. 置顶评论 1–2 条
3. 回复话术卡（按类型）
4. 可沉淀为下期选题的问题列表
5. 需人工处理的风险评论

## 交棒

发现选题 → `self-media-content-brief`  
导私域 → `self-media-private-domain`
