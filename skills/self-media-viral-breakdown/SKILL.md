# 单条爆款深拆（优化版）

## 目标

4–8 分钟内看懂「这条为什么能传」，并给出可拍的机制版，不抄原句。

## 输入

- 链接 / 封面截图 / 文案 / 口播要点（有原片更好）
- 平台
- 你的赛道（用于判断能不能迁）

缺信息最多问 3 个。

## 流程

1. **固定事实**：时长、文案、话题、公开互动、发布时间、账号定位线索。  
2. **互动结构**：算转/赞、藏/赞、评/赞（播放缺失则标明）。判断驱动类型：  
   - 转藏驱动（金句/清单）  
   - 完播驱动（剧情/教程节奏）  
   - 评论驱动（争议/选择题）  
3. **钩子时钟**：0–0.8 / 0.8–1.8 / 1.8–3.0 各完成什么。  
4. **结构定型**：清单 / 故事 / 对立金句 / 演示 / 避坑 / 对比。  
5. **封面模板**：大字报 / 人像情绪 / 前后对比 / 结果墙 / 场景痛点。  
6. **可迁 vs 不可抄**：机制 ≤5 条；皮囊、金句、脸、独特经历不可抄。  
7. **机制仿写**：3 标题 + 3 封面大字 + 开头钩子 + CTA（换你的证据）。

## 交付（固定）

1. 一句话：这条的传播发动机是什么  
2. 事实表 + 证据等级  
3. 钩子时钟与结构类型  
4. 可迁移机制 / 不可复制资源  
5. 机制仿写包（可粘贴）  
6. 是否建议进入你的对标短名单
