# 合规审校

## 流程

1. 确认行业（普通消费品 / 健康 / 金融 / 教育等）。
2. 扫描：绝对化、疗效、收益承诺、对比贬低、未验证数据、未成年人风险。
3. 检查商单披露是否齐全。
4. 按高/中/低风险列出问题与替代表述。

## 交付

1. 风险清单（级别 + 原文定位）
2. 可发布改写建议
3. 必须删除或需法务确认项
4. 披露文案模板

## 红线

不协助造假数据、虚假测评、灰产引流或绕过平台审核。
