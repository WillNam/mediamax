# 长内容切片工厂

## 输入

- 源内容：链接、文稿、时间轴或要点
- 目标平台与条数
- 保留的人设与禁区

## 流程

1. 标出高势能片段：冲突、结果、步骤、金句、反转。
2. 每个切片只保留一个判断。
3. 写独立钩子（不依赖上下集也能看懂）。
4. 标注建议时长、需要补拍/字幕的缺口。

## 交付

1. 切片清单（时间码/段落 + 一句话卖点）
2. 每条的封面标题候选
3. 发布顺序建议（先强后深）
4. 不建议切片的段落及原因

## 交棒

细脚本 → `self-media-short-video`  
封面 → `self-media-cover-director`
