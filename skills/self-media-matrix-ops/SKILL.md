# 矩阵号运营

## 输入

- 现有账号列表与定位
- 团队产能与负责人
- 业务目标：测赛道 / 铺货 / 分流私域

## 方法

1. 一号一职责：获客号 / 信任号 / 转化号 / 测试号。
2. 内容资产分层：母题共享，表达重写，禁止原片多号同发（除非策略允许且改包装）。
3. 错峰与复用规则：首发平台、二次改装窗口。
4. 风险隔离：商单、舆情、违规号不影响主号。

## 交付

1. 矩阵地图（账号×职责×KPI）
2. 内容协同表
3. 周排期模板
4. 禁令清单（同质化、互导过度、人设冲突）

## 交棒

单号策略 → `self-media-content-strategy`  
排期 → `self-media-traffic-planner`
