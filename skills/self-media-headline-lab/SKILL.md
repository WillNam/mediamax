# 标题实验室（优化版）

## 原则

- 内部多生成，对外少展示（建议 8→3）。  
- 标题承诺必须在前 10 秒兑现。  
- 禁止无证据的绝对化与医疗金融违规承诺。

## 公式池（选用，不堆砌）

1. 数字 + 结果  
2. 人群 + 痛点  
3. 冲突 / 反常识  
4. 错误警告  
5. 前后对比  
6. 清单体  
7. 场景代入  
8. 提问缺口  

## 流程

1. 确认平台、核心判断、可用证据。  
2. 生成 8 个标题。  
3. 删除：无法兑现 / 违规 / 空泛 / 与封面重复信息。  
4. 输出 Top3，每个附：入口类型、点击假设、风险。  
5. 给 1 个「标题×封面」联测方案（本周只测一组）。

## 交付

```markdown
## 标题实验室
- 推荐 Top3：
  1. …
  2. …
  3. …
- 淘汰原因摘要：
- 联测：标题A + 封面大字B，观察窗口 __，成功标准 __
```
