# 发布前检查清单（优化版）

## 用法

对即将发布的成稿 / 分镜 / 封面执行一遍。有一项高风险未解决 → 不建议发。

## 清单

见 [assets/preflight.md](assets/preflight.md)。

## 分级

| 级 | 含义 | 动作 |
|---|---|---|
| 阻断 | 违规/虚假/封面无钩子/标题不兑现 | 必须改 |
| 警告 | 弱 CTA、标签随意、证据不足 | 建议改 |
| 通过 | 可发 | 记录版本 |

## 交付

1. 通过 / 警告 / 阻断 汇总  
2. 必须修改的原文定位  
3. 改写建议（可粘贴）  
4. 披露文案（若商单）

## 交棒

合规深审 → `self-media-compliance`  
舆情预案 → `self-media-crisis-desk`
