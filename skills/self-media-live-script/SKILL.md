# 直播脚本

## 输入

- 直播目标：卖货 / 涨粉 / 答疑 / 品宣
- 时长、产品或主题、是否有助播
- 历史坑点（若有）

## 结构（可调）

| 时段 | 任务 |
|---|---|
| 0–10% | 留人：福利预告 + 今晚只解决一个问题 |
| 10–40% | 信任：演示/案例/对比 |
| 40–70% | 转化：报价、异议处理、社会证明 |
| 70–90% | 逼单：限时、套餐、问答清库存 |
| 90–100% | 收尾：复盘、下播预告、私域入口 |

## 交付

1. 分场时间盒脚本
2. 主播话术卡（开场/异议/逼单/翻车救场）
3. 助播指令单（弹幕、置顶、链接）
4. 数据盯盘指标：在线、点击、转化
5. 下播 30 分钟复盘清单

## 交棒

切片二次分发 → `self-media-clip-factory`  
私域承接 → `self-media-private-domain`
