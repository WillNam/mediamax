# 系列内容工厂

## 输入

- 账号定位与栏目（若无则先问诊或调用策略模块）
- 产能：每周几条
- 系列目标：涨粉 / 信任 / 转化

## 流程

1. 选 1 个主系列（不要同时开 5 个）。
2. 写系列承诺、受众、更新频率、停止条件。
3. 产出 8–12 期大纲：每期一个判断 + 证据类型 + 钩子方向。
4. 统一包装：片头句、结尾 CTA、封面模板变量。

## 交付

1. 系列说明书（1 页）
2. 分集大纲表
3. 前 3 期完整可拍要点（可再交短视频模块细化）
4. 合集命名与封面统一规则
5. 本周期唯一实验变量

## 交棒

单期细脚本 → `self-media-short-video`  
排期 → `self-media-traffic-planner`
