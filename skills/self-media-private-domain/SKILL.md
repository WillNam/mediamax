# 公域到私域

## 目标

让对的人愿意留下联系方式，并知道留下来能持续得到什么。

## 流程

1. 定义私域承诺（每周给什么，不给什么）。
2. 设计路径：内容 CTA → 私信关键词 → 欢迎语 → 社群/名单。
3. 写 7 天暖场内容节奏（别一进来就强卖）。
4. 设转化节点：资料、体验、咨询、购买。

## 交付

1. 路径图（一页）
2. 视频/图文 CTA 文案
3. 私信自动回复文案（人工配置）
4. 欢迎语与社群规矩
5. 7 天内容日历 + 禁止事项

## 红线

不建议买粉、互粉刷量、诱导分享个人敏感信息。
